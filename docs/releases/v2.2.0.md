# Local Dictation 2.2.0 public preview

This update makes Local Dictation easier to find and use as a Mac app, and fixes microphone controls that could appear unresponsive after downloading it.

- **A normal app window and Dock icon.** Home opens on launch and when you reopen the app. A native sidebar leads to Microphone, General, Shortcuts, Custom Words, and Advanced. Setup and microphone testing have direct buttons on Home.
- **Microphone controls work while models load.** Choosing and testing an input no longer depends on the speech models being ready. Dictation and recovery still have exclusive access to audio capture.
- **Changing microphones keeps your choice.** Previously, switching devices during a microphone test could restore the old selection before saving. The newly selected device is now saved and used by the next test or recording.
- **A direct permission route.** Microphone shows whether access is allowed. Allow microphone requests the first grant; Open Microphone Settings takes you to the macOS permission screen when access is off. Testing without permission uses this route.
- **Familiar Mac controls.** The app has native application, Edit, and Window menus. Closing the window leaves your shortcut running. Quit Local Dictation stops the app and retains the existing pending-result safeguards.

## Installation and update

[Download the Mac preview DMG](https://github.com/ysham123/imnotpayingforwisprflow/releases/download/v2.2.0/Local-Dictation.dmg), drag Local Dictation to Applications, eject the image, and open the installed app. Finish any dictation and quit the old app before replacing it. Existing verified models and preferences are reused. In Home, choose Start or resume setup if needed.

The app and disk image are Developer ID signed and notarized by Apple, with stapled tickets. This update has the same Developer ID designated requirement as 2.1.0; permission continuity across that update remains unverified until an installed-app check. macOS privacy approvals are still required. [2.0.1](https://github.com/ysham123/imnotpayingforwisprflow/releases/tag/v2.0.1) remains the latest stable release.

## Validation and limits

The native window was rendered at normal and minimum sizes. Injected microphone tests exercise actual NSControl target/action dispatch, selection during a running test, permission recovery, model-loading availability, navigation, and busy-state exclusion. These fixtures do not capture physical microphone audio or grant macOS permissions. Headless audio policy, existing audio recovery, packaging, and thin-release regressions pass. The full GitHub macOS workflow passed for the packaged code. Both Apple notarization submissions were Accepted with no reported issues. The final DMG’s mounted app and a real copy into an isolated Applications folder match the candidate byte for byte and pass signature, stapled-ticket, and Gatekeeper checks. See the [verification record](../benchmarks/v2.2.0/release-verification.json).

Real-microphone interaction in the installed update and a complete fresh-Mac permission/download/shortcut/practice/insertion run remain unverified. Native recognition and correction engines and model weights are unchanged. Apple Silicon, macOS 14+, and English dictation are supported; no Intel, Windows, or iPhone app is provided.
