# Local Dictation 2.2.1 public preview

This update fixes false “The microphone changed” interruptions that could stop dictation just after it started.

- **Keep recording through harmless audio changes.** A delayed startup notification or output-device reconfiguration no longer stops a microphone that is still running with the same input and format.
- **Recover a stopped audio engine.** When the same microphone and format remain available, the app can restart the engine while retaining the audio already captured. Recovery is bounded; repeated failures stop with an explanation.
- **Keep real device changes safe.** A disconnected microphone or changed input format still ends capture and retains the speech captured so far. Cancelled or finished recordings cannot be restarted by a queued notification.

The Home window, Dock icon, microphone controls, guided setup, local models, and recognition/correction engines from [2.2.0](v2.2.0.md) remain available.

## If Fn double-tap does nothing

Apple Dictation can use the same gesture. In **System Settings → Keyboard**, set **Press 🌐 key to** to **Do Nothing**, then choose a different **Dictation → Shortcut**, such as pressing Right Command twice. Local Dictation does not change macOS shortcuts automatically. You can also choose a custom shortcut in Local Dictation’s **Shortcuts** section; setup offers Control-Shift-Space.

## Install or update

[Download the Mac preview DMG](https://github.com/ysham123/imnotpayingforwisprflow/releases/download/v2.2.1/Local-Dictation.dmg). Finish any dictation and quit the old app, drag Local Dictation to Applications, eject the disk image, and open the installed app. Existing models and preferences are reused.

The app and DMG are Developer ID signed, notarized by Apple, and include stapled tickets. The signing requirement matches the previous preview. Microphone, Accessibility, and Input Monitoring approvals were retained across the 2.2.0 → 2.2.1 update on the development Mac. This is not a guarantee for every Mac. [2.0.1](https://github.com/ysham123/imnotpayingforwisprflow/releases/tag/v2.0.1) remains the latest stable release.

## Validation and limits

The full GitHub macOS workflow passed for the packaged code. Audio regressions cover harmless configuration, same-input restart, bounded failure, disconnect/format-change handling, prefix retention, and late buffers after cancellation. In the installed update, two real MacBook microphone preview start/stop checks passed, the level meter showed input, and a compatible configuration notification kept recording active. No microphone recording was saved. The creator subsequently confirmed using dictation successfully in the installed update.

Both Apple notarization submissions were Accepted with no reported issues. The final DMG’s mounted app, isolated Applications copy, and installed app match the signed candidate byte for byte. Signature, stapled-ticket, and Gatekeeper checks pass. See the [verification record](../benchmarks/v2.2.1/release-verification.json).

The exact physical shortcut was not independently observed. A real device unplug, stopped-engine recovery on hardware, and complete first-time setup on a fresh Mac remain unverified. The preview supports English dictation on Apple Silicon and macOS 14+. There is no Intel, Windows, or iPhone app.
