LOCAL DICTATION · MAC SETUP

Your first dictation, step by step.

For an Apple Silicon Mac (M1 or newer), macOS 14+. Keep 8 GB free. Models download about 3.4 GB once, then dictation works offline.

1. Open the app in this disk image.

Double-click Local Dictation.app, then choose Install & Open. The verified copy opens from Applications.

If macOS blocks opening this community build, try opening it first, then use System Settings → Privacy & Security → Open Anyway if you trust it. Confirm Open. Apple’s opening instructions.

2. Choose Start setup.

The walkthrough explains each permission before asking for it. Choose Allow for Microphone; turn on Local Dictation for Accessibility and Input Monitoring. Return to setup after each approval. If macOS asks you to quit and reopen the app, do so.

System Settings → Privacy & Security → [permission] → Local Dictation

3. Download the models.

Keep your Mac online. The walkthrough shows downloaded size, speed, and an estimated remaining time while downloading. Pause and resume when needed. Files are checked before use.

4. Choose and test a shortcut.

Try Control-Shift-Space if you do not already use it. Press your shortcut when setup asks you to check it. This key test does not record audio. You can choose another shortcut, or keep Fn / Globe after freeing that key in Keyboard Settings.

5. Try a sentence inside setup.

Start practice dictation, say a short sentence, and finish. The app shows your words inside setup. Review them and finish setup. Your practice words are not pasted into another app or saved as transcript history.

Then click a text box in your usual app and use the same shortcut to dictate. Local Dictation stays in the microphone menu in your Mac’s menu bar.
